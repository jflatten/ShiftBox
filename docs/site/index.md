# Run ShiftBox in your AWS account

ShiftBox gives developers and coding agents a private workspace with the tools defined by their project's devcontainer. Each workspace runs on its own EC2 VM, and developers can open its IDE in their browser.

An official AWS release includes a CloudFormation template and prebuilt images. Choose a region for console setup or use the guided Bash installer. Both paths use the same release assets.
